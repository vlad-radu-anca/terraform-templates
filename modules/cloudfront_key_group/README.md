# AWS Cloudfront Keygroup  Module

[User Guide](https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/cloudfront_key_group#attributes-reference)

## Terraform versions

Terraform 0.13.6
AWS Provider Version 3.38.0


## Usage

* Cloudfront keygroup
  ``` hcl
  module "keygroup" {
    source                              = "./modules/cloudfront_key_group"
    keys = {
      "public_key": {
        "comment": "public key",
        "file_name": "public_key.pem"
      }
    }
    key_group_name = "key_group_name"
  }
  ```

## Inputs

| Name | Description | Type | Default |
|------|-------------|------|---------|
| key_group_name | A name to identify the key group | `string` |  |
| keys | The variables for keys | `map(object({}))` | |


## keys
Sample value for keys ( it will create two keys)
```
{
    "key1": {
      "comment": "public key",
      "file_name": "public_key.pem",
    },
     "key2": {
      "comment": "public key2",
      "file_name": "public_key2.pem"
      }
    
}
```

| Name | Description | Type | Default |
|------|-------------|------|---------|
| name |  (Optional) The name for the public key. By default generated by Terraform ( the key of keys variable will be used as name)| `string` |  |
| comment | (Optional) An optional comment about the public key) | `string` |  |
| file_name |  (Required) The file name containing encoded public key that you want to add to CloudFront to use with features like field-level encryption. | `string` |  |
